Lesson Overview

프로젝트 개요 및 시스템 구조

구글 스프레드시트를 데이터베이스로 활용하고, GitHub Pages를 이용해 언제 어디서나 스마트폰에 설치할 수 있는 PWA(Progressive Web App) "한 줄 메모장"을 제작해 봅니다.

프론트엔드 (PWA)

GitHub Pages 호스팅

  • • 사용자 화면 UI (HTML/CSS)
  • • PWA 앱 설치 지원 (`manifest`)
  • • 오프라인 캐싱 (`sw.js`)
HTTP POST (JSON)

백엔드 & DB

Google Apps Script

  • • `doPost(e)` API 엔드포인트
  • • 수신된 메모 데이터 처리
  • • 구글 스프레드시트에 자동 기록
💡 왜 이 방식을 사용하나요? GAS 웹 앱은 manifest.json·sw.js 같은 정적 파일을 직접 호스팅할 수 없어 PWA(서비스 워커 등록)를 구성하기 어렵습니다. 따라서 정적 웹 호스팅인 GitHub Pages에 프론트엔드를 두고, GAS를 API 서버로 연결하는 표준적인 방식을 사용합니다.

먼저 쉬운 비유로 이해하기

GitHub Pages = 가게 간판과 진열대(사람들이 보고 누르는 화면) / Google Apps Script = 주문을 받아 적는 비서 / 스프레드시트 = 주문 장부
손님(나)이 화면에 메모를 적어 [전송]을 누르면 → 비서(GAS)가 받아서 → 장부(시트)에 한 줄 적어 줍니다.

데이터를 '보내는 방식' / 데이터를 담는 '글자 형식'
PWA
웹사이트를 스마트폰 앱처럼 설치해 쓰는 기술

PWA(Progressive Web App)의 핵심 원리

PWA는 일반 웹 사이트에 Manifest(앱 설정)와 Service Worker(오프라인 캐싱)를 결합하여, 스마트폰이나 PC에 실제 애플리케이션처럼 설치해서 사용할 수 있게 해주는 기술입니다.

[심화] CORS(크로스 오리진) 이슈

눌러서 펼치기 (심화 내용 - 처음엔 건너뛰어도 됩니다)

GitHub Pages 도메인과 GAS 도메인이 달라 브라우저의 보안 정책(CORS)이 적용됩니다. 이를 피하기 위해 요청 헤더의 Content-Type을 text/plain으로 보내 '단순 요청(Simple Request)'으로 만들면, 사전 검사(Preflight) 없이 데이터를 전송할 수 있습니다.

Step 1 : Backend Setup

1단계: Google Apps Script API 구축

구글 스프레드시트에 데이터를 자동 기록하는 백엔드 API를 생성합니다. ⏱ 예상 15분

  1. Google 드라이브에서 새 구글 스프레드시트를 만들고 하단 시트 탭 이름을 data로 변경합니다.
  2. 상단 메뉴 [확장 프로그램] > [Apps Script]를 클릭합니다.
  3. 기존 코드 대신 아래 코드를 복사하여 Code.gs에 붙여넣습니다.
Code.gs 
// 웹 앱 주소를 브라우저에서 열어 'OK'가 보이면 배포가 정상입니다.
function doGet(e) {
  return ContentService.createTextOutput('OK');
}

function doPost(e) {
  try {
    // 1. 전달받은 JSON 데이터 파싱
    var data = JSON.parse(e.postData.contents);

    // 1-1. 메모 검사: 비어 있으면 오류, 수식(= + - @)으로 시작하면 문자로 저장
    var memo = String(data.memo || '').trim();
    if (!memo) throw new Error('메모 내용이 비어 있습니다.');
    memo = memo.replace(/^([=+\-@])/, "'$1");
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    var sheet = ss.getSheetByName('data');
    
    // 2. 'data' 시트가 없으면 자동 생성
    if (!sheet) {
      sheet = ss.insertSheet('data');
    }
    
    // 3. 헤더 셀이 비어있으면 초기화
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(['내용', '시간']);
    }
    
    // 4. 현재 시간 생성 (YYYY-MM-DD HH:mm:ss)
    var now = Utilities.formatDate(new Date(), Session.getScriptTimeZone(), 'yyyy-MM-dd HH:mm:ss');
    
    // 5. 시트에 데이터 추가
    sheet.appendRow([memo, now]);
    
    return ContentService.createTextOutput(JSON.stringify({ result: 'success' }))
      .setMimeType(ContentService.MimeType.JSON);
      
  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({ result: 'error', message: error.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
⚠️ 중요! 웹 앱 배포 설정 우측 상단 [배포] > [새 배포] ➔ 유형: 웹 앱 선택
• 다음 사용자 권한으로 실행: 나(Me) 로 설정
• 액세스 권한 있는 사용자: 모든 사용자 (Anyone) 로 변경 후 배포!
• 배포 후 생성된 웹 앱 URL을 반드시 복사하세요! 브라우저 주소창에 붙여넣어 OK가 보이면 성공입니다.
• 💡 구글 보안 경고가 나타나는 경우: [고급(Advanced)] ➔ [(안전하지 않은 페이지로 이동)] ➔ [허용(Allow)]을 순서대로 클릭하여 진행합니다.
✅ 확인하기: 1단계가 잘 끝났는지 점검
  • 복사한 웹 앱 URL을 브라우저 새 탭 주소창에 붙여넣으면 화면에 OK가 보인다.
  • 웹 앱 URL을 메모장 등에 따로 적어 두었다. (2단계에서 사용합니다)
  • 실행 권한: 나(Me), 액세스: 모든 사용자로 배포했다.

GAS 주요 주요 기능 한 줄 해설

doGet(e): 주소창으로 접속했을 때 'OK'를 돌려주는 동작 확인용 함수
doPost(e): 클라이언트에서 POST 방식으로 전송한 요청을 수신하는 웹훅 메인 함수
replace(/^([=+\-@])/, ...): 시트에서 수식으로 실행되지 않도록 앞에 ' 를 붙여 문자로 저장
e.postData.contents: 웹 페이지에서 보낸 JSON 문자열 데이터 수신
sheet.appendRow([...]): 시트 맨 마지막 줄에 배열 항목을 새로운 행(Row)으로 입력
ContentService...: 데이터 처리 결과를 JSON 형식 문자열로 응답 전달
Step 2 : Frontend & PWA Files

2단계: 프론트엔드 및 PWA 설정

GitHub 저장소에 올릴 파일은 코드 3개(index.html, manifest.json, sw.js)와 아이콘 이미지 2개입니다. 각 탭을 눌러 소스코드를 복사하세요. ⏱ 예상 20분

GitHub 웹사이트에서 3개 파일 직접 만드는 방법 (초보자 가이드)

1단계: 저장소(Repository) 만들기

GitHub 메인에서 우측 상단 [+] ➔ [New repository] 클릭
• Repository name: my-memo-pwa
• Public 선택 (무료 배포 필수)
• Add a README file 체크 후 [Create repository] 클릭!

2단계: 새 파일 생성 및 코드 작성

생성된 저장소 화면에서 [Add file] ➔ [Create new file] 클릭
• 파일명 입력란에 index.html 입력
• 본문 입력 창에 아래 탭에서 복사한 index.html 소스코드 붙여넣기

3단계: 저장하기 (Commit Changes)

우측 상단 녹색 [Commit changes...] 클릭 ➔ 팝업창에서 다시 [Commit changes] 클릭하면 저장 완료!
※ manifest.json과 sw.js 파일도 동일한 방법으로 만들고, 아이콘 이미지 2개(icon-192.png, icon-512.png)는 [Add file] ➔ [Upload files]로 올립니다.

⚠️ 꼭 먼저 읽으세요! index.html을 저장(Commit)하기 전에
  1. 붙여넣은 코드에서 "여기에_1단계에서_복사한_URL을_붙여넣으세요" 부분을 따옴표는 남기고 안의 글자만 1단계에서 복사한 웹 앱 URL로 바꿉니다.
  2. 예) const GAS_URL = "https://script.google.com/macros/s/....../exec";
  3. 저장한 뒤에 고치려면: 저장소에서 index.html 클릭 ➔ 오른쪽 위 연필(✏️) 아이콘 ➔ 수정 ➔ Commit changes

📥 아이콘 이미지 2개(icon-192.png, icon-512.png)는 선생님이 안내한 구글 드라이브(또는 클래스룸) 링크에서 내 컴퓨터로 내려받은 뒤, 저장소에서 [Add file] ➔ [Upload files]로 올리고 Commit 합니다. (파일 이름을 바꾸면 안 됩니다)

index.html (GAS_URL 부분에 1단계 URL 적용) 
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>한 줄 메모장</title>
  <link rel="manifest" href="manifest.json">
  <meta name="theme-color" content="#4CAF50">
  <link rel="apple-touch-icon" href="icon-192.png">
  <style>
    body { font-family: sans-serif; padding: 20px; max-width: 400px; margin: 0 auto; }
    .input-group { display: flex; gap: 8px; margin-top: 15px; }
    input { flex: 1; padding: 10px; border: 1px solid #ccc; border-radius: 4px; }
    button { padding: 10px 16px; background-color: #4CAF50; color: white; border: none; border-radius: 4px; cursor: pointer; }
    button:disabled { background-color: #ccc; }
    #status { margin-top: 10px; font-size: 13px; color: #666; }
    #installBox { margin-top: 20px; padding: 14px; background: #e8f5e9; border-radius: 8px; display: none; }
    #installBtn { width: 100%; padding: 12px; font-size: 16px; font-weight: bold; }
    #installHelp { margin: 10px 0 0; font-size: 13px; color: #2e5d31; line-height: 1.5; }
  </style>
</head>
<body>
  <h3>📝 나만의 한 줄 메모장 (PWA)</h3>
  <div class="input-group">
    <input type="text" id="memoInput" placeholder="메모할 내용을 입력하세요">
    <button id="sendBtn" onclick="sendMemo()">전송</button>
  </div>
  <div id="status"></div>

  <!-- 앱 설치 안내: 주소창을 못 찾는 학생을 위해 화면 안에 설치 버튼을 둡니다 -->
  <div id="installBox">
    <button id="installBtn">📲 앱으로 설치하기</button>
    <p id="installHelp"></p>
  </div>

  <script>
    // 1. 서비스 워커 등록
    if ('serviceWorker' in navigator) {
      navigator.serviceWorker.register('sw.js')
        .then(() => console.log('Service Worker Registered'));
    }

    // 설치 버튼 (PWA 설치를 화면 안에서 바로 할 수 있게 해 줍니다)
    let deferredPrompt = null;
    const installBox = document.getElementById('installBox');
    const installBtn = document.getElementById('installBtn');
    const installHelp = document.getElementById('installHelp');
    const isStandalone = window.matchMedia('(display-mode: standalone)').matches || navigator.standalone === true;
    const isIOS = /iphone|ipad|ipod/i.test(navigator.userAgent);

    // 이미 앱으로 실행 중이면 설치 버튼을 보여 주지 않음
    if (!isStandalone) installBox.style.display = 'block';

    // 크롬/엣지/안드로이드: 설치 준비가 되면 브라우저가 이 이벤트를 보내 줌
    window.addEventListener('beforeinstallprompt', (e) => {
      e.preventDefault();
      deferredPrompt = e;
    });

    window.addEventListener('appinstalled', () => {
      installBox.style.display = 'none';
    });

    installBtn.addEventListener('click', async () => {
      if (deferredPrompt) {
        // 설치 팝업을 바로 띄움
        deferredPrompt.prompt();
        await deferredPrompt.userChoice;
        deferredPrompt = null;
      } else if (isIOS) {
        installHelp.innerText = '아이폰/아이패드는 Safari에서 아래 가운데 [공유(□↑)] 버튼 ➔ [홈 화면에 추가]를 눌러 주세요. (카카오톡 등 앱 안의 브라우저에서는 안 됩니다)';
      } else {
        installHelp.innerText = '크롬 주소창 오른쪽의 설치 아이콘(⊕) 또는 오른쪽 위 ⋮ 메뉴 ➔ [앱 설치] / [홈 화면에 추가]를 눌러 주세요. 이미 설치했다면 앱 목록에서 실행하세요.';
      }
    });

    // 2. 구글 앱 스크립트 웹 앱 URL 붙여넣기
    const GAS_URL = "여기에_1단계에서_복사한_URL을_붙여넣으세요";

    async function sendMemo() {
      const input = document.getElementById('memoInput');
      const btn = document.getElementById('sendBtn');
      const status = document.getElementById('status');
      const text = input.value.trim();

      if (!text) return alert('내용을 입력하세요.');

      btn.disabled = true;
      status.innerText = '저장 중...';

      try {
        const res = await fetch(GAS_URL, {
          method: 'POST',
          headers: { 'Content-Type': 'text/plain;charset=utf-8' },
          body: JSON.stringify({ memo: text })
        });

        // 서버(GAS)가 돌려준 결과를 확인해서 실패하면 오류로 처리
        const result = await res.json();
        if (result.result !== 'success') {
          throw new Error(result.message || '서버 오류');
        }

        input.value = '';
        status.innerText = '✅ 성공적으로 저장되었습니다!';
        setTimeout(() => { status.innerText = ''; }, 2000);
      } catch (err) {
        status.innerText = '❌ 저장 실패: ' + err.message;
      } finally {
        btn.disabled = false;
      }
    }
  </script>
</body>
</html>
🔍 index.html 핵심 코드 포인트
  • <link rel="manifest" href="manifest.json">: 웹 브라우저에 이 사이트가 PWA 설치를 지원함을 선언합니다.
  • navigator.serviceWorker.register('sw.js'): 백그라운드 캐싱을 담당할 서비스 워커 파일 등록 함수입니다.
  • beforeinstallprompt: 브라우저가 "설치할 수 있어요"라고 알려 줄 때 받아 두었다가, 화면의 [📲 앱으로 설치하기] 버튼을 누르면 설치 팝업을 띄웁니다. (아이폰은 이 기능이 없어서 안내 문구를 보여 줍니다)
  • await res.json(): GAS가 돌려준 처리 결과를 읽어, 실패했는데 성공으로 표시되는 일을 막습니다.

🔍 manifest.json 핵심 주요 속성
  • "display": "standalone": 브라우저의 URL 주소창과 메뉴바를 제거하고 스마트폰 앱처럼 독립 실행창으로 실행합니다.
  • "icons": 192x192(홈 화면 아이콘) 및 512x512(스플래시 스크린 아이콘) 필수 규격을 지정합니다.
  • ⚠️ 선생님이 나눠 준 icon-192.png, icon-512.png 두 파일을 저장소에 [Add file] ➔ [Upload files]로 꼭 올려야 합니다. (파일명이 다르면 설치 버튼이 나타나지 않습니다)
sw.js (오프라인 서비스 워커) 
const CACHE_NAME = 'memo-pwa-v1';
const ASSETS = [
  './',
  './index.html',
  './manifest.json',
  './icon-192.png',
  './icon-512.png'
];

// 설치: 필요한 파일을 캐시에 저장
self.addEventListener('install', (e) => {
  e.waitUntil(
    caches.open(CACHE_NAME).then((cache) => cache.addAll(ASSETS))
  );
  self.skipWaiting();
});

// 활성화: 이름이 다른 옛 캐시 삭제 (CACHE_NAME을 바꾸면 이전 캐시가 정리됨)
self.addEventListener('activate', (e) => {
  e.waitUntil(
    caches.keys().then((keys) =>
      Promise.all(keys.filter((k) => k !== CACHE_NAME).map((k) => caches.delete(k)))
    )
  );
  self.clients.claim();
});

// 요청 처리: 네트워크 우선, 오프라인이면 캐시 사용
self.addEventListener('fetch', (e) => {
  // GAS로 보내는 POST 등 GET이 아닌 요청은 건드리지 않음
  if (e.request.method !== 'GET') return;

  e.respondWith(
    fetch(e.request)
      .then((res) => {
        const copy = res.clone();
        caches.open(CACHE_NAME).then((cache) => cache.put(e.request, copy));
        return res;
      })
      .catch(() => caches.match(e.request))
  );
});
🔍 sw.js 작동 라이프사이클
  • install 이벤트: 최초 방문 시 ASSETS 배열에 정의된 정적 파일(HTML, JSON 등)을 브라우저 로컬 캐시에 저장합니다.
  • activate 이벤트: 이름이 다른 옛 캐시를 지웁니다. 코드를 크게 바꿀 때는 CACHE_NAME(예: v2)을 바꿔 주세요.
  • fetch 이벤트: 평소에는 네트워크에서 최신 파일을 받아 오고, 오프라인이면 저장된 캐시로 화면을 보여 줍니다. POST(메모 전송)는 처리하지 않습니다.
  • ※ 오프라인에서는 화면만 열리며, 메모 전송은 인터넷이 연결되어야 합니다.
✅ 확인하기: 2단계가 잘 끝났는지 점검
  • 저장소(Code 탭) 파일 목록에 index.html, manifest.json, sw.js, icon-192.png, icon-512.png가 모두 보인다. (README.md는 있어도 됩니다)
  • 파일 이름의 영문 대소문자와 확장자가 정확하다. (Index.html, index.html.txt는 오류의 원인!)
  • index.html 안의 GAS_URL이 내 웹 앱 URL로 바뀌어 있다.

Troubleshooting

자주 발생하는 오류 & 트러블슈팅

실습 중 문제가 발생하면 아래 사항을 먼저 점검해 보세요.

Q. 메모를 보냈는데 스프레드시트에 저장되지 않아요!

1) GAS 배포 시 액세스 권한을 '모든 사용자(Anyone)'로 설정했는지 확인합니다.
2) 웹 앱 URL을 브라우저 주소창에 붙여넣어 OK가 보이는지 확인합니다. index.html의 GAS_URL이 이 주소와 같은지도 확인하세요.
3) GAS 코드를 수정했다면 반드시 [배포] > [배포 관리] > [수정 아이콘] ➔ 새 버전으로 배포해야 수정 내용이 반영됩니다.

Q. 브라우저 콘솔에 CORS 관련 에러가 발생합니다.

GAS 웹 앱은 보안상 CORS 구문 제한이 큽니다. JS `fetch` 요청 시 헤더의 `Content-Type`을 text/plain;charset=utf-8 로 설정했는지 확인하세요 (Simple Request 우회).

Q. PWA 앱 설치 버튼이 뜨지 않아요.

먼저 앱 화면 아래의 [📲 앱으로 설치하기] 버튼을 눌러 보세요. 그래도 안 되면 PWA 설치 요건인 1) HTTPS 프로토콜 (GitHub Pages), 2) 유효한 manifest.json, 3) 등록된 서비스 워커(sw.js)가 준비되었는지 확인하세요. 개발자 도구(F12) ➔ [Application] 탭에서 상태를 검사할 수 있습니다.

Q. GitHub Pages 주소로 들어갔더니 404(페이지를 찾을 수 없음)가 나와요.

1) 설정 후 1~2분 기다린 뒤 새로고침합니다.
2) 저장소 Code 탭에 index.html이 맨 바깥(폴더 안이 아닌 곳)에 있는지, 이름이 정확한지(Index.html, index.html.txt 아님) 확인합니다.
3) Settings ➔ Pages에서 Branch가 main / / (root)로 저장되어 있는지, 저장소가 Public인지 확인합니다.
4) 주소 끝에 저장소 이름이 빠지지 않았는지 확인합니다. (https://아이디.github.io/my-memo-pwa/)

Q. "❌ 저장 실패: Failed to fetch" 또는 "서버 오류"가 떠요.

1) index.html의 GAS_URL을 내 웹 앱 URL로 바꿨는지 확인합니다. (자리표시자 글자가 그대로면 실패합니다)
2) 그 URL을 브라우저 주소창에 붙여넣었을 때 OK가 보이는지 확인합니다. 안 보이면 GAS 배포부터 다시 점검합니다.
3) 코드를 수정하고 다시 배포했다면 새 버전으로 배포했는지 확인합니다.

막히면 나만의 Gem에게 이렇게 물어보세요 (바이브 코딩!)

  • "브라우저 콘솔(F12)에 이런 빨간 에러가 떠: [에러 메시지 붙여넣기]. 원인을 쉬운 말로 설명하고 고친 코드를 알려줘."
  • "GitHub Pages 주소가 404야. 내 저장소 파일 목록은 [파일 이름들 적기]인데 뭐가 문제일까?"
  • "아래 GAS 코드를 한 줄씩 쉬운 말로 설명해줘: [코드 붙여넣기]"

도전 미션: 내 앱으로 업그레이드하기

  • "메모 입력칸 외에 '카테고리' 선택 칸을 추가하고, 스프레드시트에도 같이 저장되게 index.html과 GAS 코드를 고쳐줘."
  • "색상과 앱 이름을 내가 좋아하는 분위기로 바꿔줘. 기능은 그대로 유지해줘."
  • ※ GAS 코드를 고치면 [배포] ➔ [배포 관리] ➔ 새 버전으로 다시 배포해야 반영됩니다.

Q. 코드를 수정했는데 웹 앱 화면에 이전 내용이 그대로 남아있어요!

서비스 워커가 기존 파일을 캐시하고 있기 때문입니다(옛 sw.js를 쓰는 경우 특히 그렇습니다). sw.js를 위 최신 코드로 바꾸고 CACHE_NAME을 v2로 올린 뒤, 크롬 브라우저에서 Ctrl + Shift + R (강제 새로고침)을 누르거나, 개발자 도구(F12) ➔ Application 탭 ➔ Service Workers 메뉴에서 Update on reload 항목을 체크하세요.
